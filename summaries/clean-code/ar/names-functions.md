# الأسماء والدوال ذات المعنى

## الأسماء
اختر أسماء تكشف عن الغرض منها بوضوح وتجنب الاختصارات المربكة.

## الدوال
يجب أن تفعل الدالة شيئاً واحداً فقط، وتفعله بشكل ممتاز ومستقل. قلل عدد الوسيطات البرمجية.
