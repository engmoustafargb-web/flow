# الحرفية البرمجية المرنة لكتاب الكود النظيف

يعلمنا كتاب "الكود النظيف" للكاتب روبرت سي مارتن أن كتابة الكود البرمجي أمر سهل، ولكن كتابة كود نظيف وقابل للصيانة هو حرفة وفن.

## التركيز الرئيسي
- قراءة الكود مقابل كتابته.
- يجب أن يُقرأ الكود النظيف بسهولة مثل النثر المكتوب جيداً.
